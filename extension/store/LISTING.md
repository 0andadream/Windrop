**Detailed description**

> WinDrop lets you gift Megapot lottery tickets to anyone on X (Twitter) — right
> from their profile.
>
> Browsing a profile? A stylish 🎟️ WinDrop button appears next to Follow. One
> tap opens WinDrop with that person pre-filled, so you can send them a shot at
> the jackpot in seconds. Prefer the toolbar? The popup auto-detects the profile
> you're viewing, lets you pick how many tickets to gift (with handy presets and
> a 🎲 surprise option), and deep-links straight into WinDrop.
>
> • One-tap gifting from any X profile
> • Quick-gift popup with ticket presets and a live total
> • Matches X's look — clean, fast, unobtrusive
> • Non-custodial: the extension only builds a link; all signing happens on the
>   WinDrop site
> • Privacy-first: no tracking, no analytics, no data collection, no background
>   scripts
>
> Powered by Megapot on Base. Not affiliated with X or Megapot.

**Single purpose** (required)

> Add a button and popup that let users gift Megapot lottery tickets to X users
> by opening a pre-filled WinDrop gift link.

---

**Permission justifications**

- **activeTab** — "Used only when the user opens the popup, to read the current
  tab's URL and pre-fill the X handle of the profile being viewed. This data
  stays in the browser."
- **Host permissions (x.com, twitter.com)** — "Required to run the content
  script that injects the WinDrop gift button next to the Follow button on
  profile pages, and to read the public @handle to build the gift link."
